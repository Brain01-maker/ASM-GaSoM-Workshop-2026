# ASM–GaSoM Microbial Genomics and Bioinformatics Workshop 2026

Welcome to the hands-on microbial genomics and bioinformatics workshop!

**Date:** Saturday, 14 November 2026  
**Venue:** CIFAL Building, UTG Kanifing Campus, The Gambia

This repository contains instructions and practical scripts for learning microbial sequencing-read quality assessment, preprocessing, and genome assembly.

## 1. Before the workshop

Please bring a laptop if you have one.

Install Docker Desktop before attending:

https://www.docker.com/products/docker-desktop/

Windows users should enable the WSL 2 backend when prompted. Linux users can install Docker Engine instead.

Start Docker and ensure it is running.

## 2. Download the workshop environment

Open a terminal (PowerShell on Windows, Terminal on macOS/Linux) and run:

```bash
docker pull lamarana01/asm-gasom-training:v1.0
```

The image includes the required bioinformatics tools, scripts, and training datasets.

**Please download the image before the workshop if you have a reliable internet connection.**

## 3. Launch the workshop environment

Create a folder to store your analysis results.

For Windows PowerShell:

```powershell
mkdir workshop-results
docker run --rm -it -v "${PWD}/workshop-results:/home/workshop/results" lamarana01/asm-gasom-training:v1.0
```

For Linux or macOS:

```bash
mkdir -p workshop-results
docker run --rm -it -v "$(pwd)/workshop-results:/home/workshop/results" lamarana01/asm-gasom-training:v1.0
```

Inside the container, check the available files:

```bash
pwd
ls
ls data
ls scripts
```

## 4. Installed bioinformatics tools

- **FastQC:** sequencing-read quality assessment
- **fastp:** read trimming and quality filtering
- **SPAdes:** genome assembly
- **Samtools:** sequencing file manipulation

## 5. Workshop datasets

The `data/` directory contains paired-end sequencing reads:

- `anc_R1.fastq.gz`
- `anc_R2.fastq.gz`

Smaller demonstration files are also included:

- `demo_R1.fastq.gz`
- `demo_R2.fastq.gz`

## 6. Practical exercises

### Exercise 1 — Sequencing-read quality assessment

```bash
bash scripts/01_fastqc.sh
```

Output: `results/fastqc/`

### Exercise 2 — Read trimming and filtering

```bash
bash scripts/02_fastp.sh
```

Output: `results/fastp/`

### Exercise 3 — Genome assembly

```bash
bash
bash scripts/03_spades.sh
```

Output: `results/spades/ancestor/`

The assembled genome contigs will be available at:

`results/spades/ancestor/contigs.fasta`

**Important:** Run the exercises in numerical order. SPAdes uses the trimmed reads generated by fastp.

## 7. Accessing your results

Analysis outputs are saved to the `workshop-results` folder on your computer through the Docker volume mount.

This allows you to retain your results after closing the container.

To exit the container:

```bash
exit
```

## 8. Troubleshooting

If Docker reports that it cannot connect to the Docker daemon, check that Docker Desktop is running.

If the image is not found, confirm that the pull command completed successfully.

If an exercise fails, inform a workshop facilitator before proceeding.
