# ASM–GaSoM Microbial Genomics and Bioinformatics Workshop

Welcome to the hands-on microbial genomics workshop!

This Docker container provides a ready-to-use environment for learning basic microbial genome analysis.

## Installed tools

- FastQC: sequencing-read quality assessment
- fastp: read trimming and quality filtering
- SPAdes: genome assembly
- Samtools: sequencing file manipulation

## Workshop dataset

The data/ directory contains paired-end sequencing reads:

- anc_R1.fastq.gz
- anc_R2.fastq.gz

The smaller demo_R1.fastq.gz and demo_R2.fastq.gz files are provided for basic command-line practice.

## Getting started

Check your working directory:

pwd
ls
ls data
ls scripts

## Exercise 1: Quality assessment

bash scripts/01_fastqc.sh

Output: results/fastqc/

## Exercise 2: Read trimming and filtering

bash scripts/02_fastp.sh

Output: results/fastp/

## Exercise 3: Genome assembly

bash scripts/03_spades.sh

Output: results/spades/ancestor/

The assembled contigs will be available in:

results/spades/ancestor/contigs.fasta

## Important notes

Run the exercises in numerical order.

The SPAdes exercise requires the trimmed reads generated by fastp.

The results/ directory should be mounted to a folder on your computer when starting Docker, so that outputs remain available after the container exits.

The workshop focuses on quality assessment, read preprocessing and genome assembly. Genome annotation is not included in this version.
